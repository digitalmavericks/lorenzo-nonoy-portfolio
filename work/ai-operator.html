02 · Client brand at Digital Mavericks

AI Operator HQ. Four paths, one readable test.

A book-trilogy funnel split into premium, downsell, high-ticket apply, and control, with path-based tagging so the CRM can tell the lanes apart.

The problem

A split you cannot tag is not a test.

Blank funnel pages are cheap. Knowing which path a contact walked, then routing thank-you copy, application questions, and follow-up to that path, is the work.

I helped stand up the four-path architecture for the book-trilogy launch, including the tagging layer that makes the experiment readable after the click. Adjacent work included branded CRM theming so the operator experience matches the brand, not a default HighLevel shell.

Path map

Four lanes. Four tags.

PATH A

Premium

Join track. Highest-intent front door. Tag on entry so nurture never mixes with the downsell.

PATH B

Lite / downsell

Start track. Same story, different offer. CRM has to know they did not see Path A copy.

PATH C

High-ticket apply

Apply track. Application questions, hold logic, human speed. Not a checkout.

PATH D

Control

Welcome baseline. The lane you keep so the other three have something honest to beat.

What I owned

Make the brand runnable.

Path-based tagging workflows so each contact carries the lane they came through. Thank-you and application surfaces that do not leak copy from another path. SaaS subaccount snapshot work so a new HighLevel location can look like AI Operators instead of a white-label CRM.

This is the same discipline as Publish & Prosper: if sales, email, and ads cannot see the path, the creative test dies in a spreadsheet.
